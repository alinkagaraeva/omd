# Анализ данных о Нобелевских лауреатах

Финальный проект курса Python. Подготовка и анализ данных о людях и организациях, получивших Нобелевскую премию.

## Что сделано

- Обработка вложенного JSON с помощью функций и конфигов для лауреатов и премий.
- Проверка пропусков, крайних значений ID, повторов и разрывов между ID.
- Анализ стран, возраста первого награждения и женщин-лауреатов: в целом, по категориям и десятилетиям.
- Графики и выводы в ноутбуке.

Расчёты выполняются без pandas и NumPy. Для среднего и медианы используется стандартный модуль `statistics`, для графиков: `matplotlib`.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `laureates_countries_task.ipynb` | Загрузка данных, проверки, анализ, графики и выводы |
| `json_dict_processing.py` | Извлечение вложенных значений и обработка словарей по конфигу |
| `laureates_configs.py` | Конфиги и процессоры людей и организаций |
| `prizes_configs.py` | Конфиг и процессор премий |
| `dataset_helpers.py` | Фильтрация, группировка, применение агрегаций и проверки данных |
| `aggregations.py` | Количество записей, среднее, медиана, максимум и топ-N |
| `atribute_manager.py` | Добавление вычисляемых полей |

## Данные

Источник: [Nobel Prize API](https://api.nobelprize.org/2.1/laureates?limit=1200).

Поскольку API возвращает 403, проект читает локальный файл `laureates.json`. Перед запуском поместите его рядом с ноутбуком, сохранив название. Сам файл данных в репозиторий не включается.

Для рейтингов стран используется `country_now`: современная страна места рождения человека или основания организации. Возраст первого награждения рассчитывается как разница года первого приза и года рождения.

## Запуск

1. Установите Python 3 и зависимости:

   ```bash
   python -m pip install jupyterlab matplotlib
   ```

2. Поместите `laureates.json` в папку проекта.
3. Из этой папки запустите JupyterLab:

   ```bash
   python -m jupyterlab
   ```

4. Откройте `laureates_countries_task.ipynb` и выполните ячейки сверху вниз.

Ноутбук также можно запускать в VS Code с расширением Jupyter, выбрав окружение с установленными `ipykernel` и `matplotlib`.
