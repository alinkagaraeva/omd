# Домашняя работа № 2: Функции

В файле `employee_reports.py` хранится решение задания.
Данные о сотрудниках находятся в `Corp_Summary.csv`.
Формулировка задания приведена ниже.

## Установка зависимостей

Нужен Python 3.10 или новее. Программа использует только стандартную библиотеку,
устанавливать дополнительные зависимости не требуется.

## Запуск

Файл `Corp_Summary.csv` должен находиться в текущей рабочей папке, из которой
запускается программа. Поэтому сначала перейдите из корня репозитория
в папку задания:

```bash
cd home_work_2
```

### Linux/macOS

```bash
python3 employee_reports.py
```

### Windows

```powershell
py -3 employee_reports.py
```

В зависимости от установки Python команда может называться `python`.

После запуска введите номер отчёта:

1. Иерархия департаментов и команд.
2. Сводка по департаментам: количество сотрудников, минимальная, максимальная
   и средняя зарплата.
3. Та же сводка с сохранением в CSV.

Средняя зарплата округляется до целого. Первые два отчёта выводятся в терминал.
Третий сохраняется в `departments_report.csv` в текущей рабочей папке;
при повторном запуске этот файл перезаписывается.

## Формулировка задания

В `Corp_Summary.csv` лежит выгрузка по сотрудникам: ФИО, департамент, команда,
должность, оценка, оклад. Колонки разделены `;`.

Напишите программу, которая читает файл и по выбранному в аргументах варианту
готовит отчёт. На экран выводите так, как вам удобно читать.

Варианты отчётов такие. Основная функция должна принимать на вход `int` - номер
варианта. Остальные параметры - по желанию:

1. Иерархия: для каждого департамента показать, какие команды в него входят.
2. Сводка по департаментам: название, сколько человек, минимальная и максимальная
   зарплата, средняя по каждому департаменту.
3. То же самое, что во втором варианте, но записанное в CSV-файл. Имя выходного
   файла можно захардкодить (например, константой в начале файла) или передавать
   опциональным параметром в эту же функцию.

Чтение файла и каждый отчёт вынесите в отдельные функции.
